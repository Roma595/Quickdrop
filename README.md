# 📦 QuickDrop

Быстрый, безопасный и красивый CLI-инструмент для передачи файлов между устройствами в локальной сети с помощью QR-кодов. Без облаков, без регистрации, без ограничений по размеру — только чистая магия P2P.

## ✨ Возможности

- 📱 **Генерация QR-кода**: Мгновенно создает QR-код для подключения мобильного устройства.
- 📤 **Отправка файлов и папок**: Бесшовная передача отдельных файлов или целых директорий (папки автоматически архивируются в ZIP на лету).
- 🎨 **Красивый веб-интерфейс**: Прием файлов через современный интерфейс с поддержкой Drag & Drop в браузере.
-  **Прогресс-бары в реальном времени**: Отслеживайте прогресс передачи с помощью красивых индикаторов прямо в терминале.
- 📋 **Интеграция с буфером обмена**: Автоматически копирует ссылку для передачи в буфер обмена.
- ️ **Умная защита от перезаписи**: Автоматически переименовывает файлы (например, в `file (1).txt`), чтобы предотвратить потерю данных.
- 🌍 **Кроссплатформенность**: Отлично работает на Windows, macOS и Linux.

## 🚀 Установка

### Вариант 1: Скачать готовые бинарники
Перейдите на страницу [Releases](https://github.com/RomaS95/Quickdrop/releases) и скачайте исполняемый файл для вашей операционной системы.

### Вариант 2: Установка через Go
Если у вас установлен Go, вы можете установить инструмент одной командой:
```bash
go install github.com/RomaS95/Quickdrop@latest
